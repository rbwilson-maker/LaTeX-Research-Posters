  \begin{exampleblock}{Motivation}

    Computer programming is \textbf{English-centric}, meaning non-English speakers face 
    barriers when learning to program \cite{guo}\cite{hermansFramework}.

    \begin{center}
      \begin{figure}
        \includegraphics[width=\textwidth]{images/Code_sidebyside.png}
      \end{figure}


      \begin{Large}
        \textbf{Should programming languages be translated or should programmers be taught English?}
      \end{Large}
    \end{center}


  \end{exampleblock}
  \vspace{-8mm}

  \begin{block}{Research Question}
    \vspace{-7mm}
    Few studies qualitatively investigate university students and their 
    experiences with non-English code.
    \textbf{How do English-speaking university students
    leverage their diverse linguistic and programming backgrounds to read non-English code?}

  \end{block}
  \vspace{-5mm}

  \begin{alertblock}{Goals}
    \vspace{4mm}
    \begin{enumerate}
      \item \textbf{Identify what skills students use to read non-English code}
      \item \textbf{Reflect on English vs. localized/non-English programming languages}
      \item \textbf{Formulate further research questions}
    \end{enumerate}
  \end{alertblock}
  \vspace{-4mm}

  \begin{block}{Approach}
    \vspace{-2mm}
    First, understand linguistic and programming backgrounds through \textbf{a survey}.
    
    Next, observe students in \textbf{interviews with a code tracing activity}.

  \end{block}
  \vspace{-4mm}

  \begin{block}{Demographics}

  \begin{block}{Language Backgrounds}
    \vspace{-7mm}
    Students listed \textbf{21 distinct languages} as "Known Well" ($\leq$ 3 per student)\\
    Top 5: English (58) Spanish (14) Mandarin (13) Hindi (5) French (4)

    \textbf{A large majority (42) were at least bilingual}, showing bias towards multilingual students.
  \end{block}
  \vspace{6mm}

  \begin{block}{Coding Backgrounds}

    \vspace{7mm}
    \begin{quotation}
      "The most difficult part of [learning to code] is juggling all of the surface level knowledge, like what tools do I have access to?"

      "I feel like it can be beneficial if we teach the core concepts of computer science at an early stage in the native language that the speakers speak."

  \vspace{-14mm}

  \begin{alertblock}{Thematic Analysis Results}
    \vspace{4mm}
    \begin{enumerate}
      \item \textbf{Syntax was one of the hardest parts of learning to program.}
      \item \textbf{Patterns in code syntax allowed students to confidently guess semantics.}
      \item \textbf{The human language of the code evoked emotional reactions for the programmer.}
      % This third point is related to Felienne's comment about how coding in one's language is not just semantic, but personal, and political even.
    \end{enumerate}
  \end{alertblock}
  \vspace{2mm}

  \begin{block}{Translate or Educate?}
    \vspace{-7mm}

    Localization of programming languages and support for non-English language
    features could increase engagement for multilingual students and lower the 
    barrier of entry to computer programming around the world. \cite{codeTranslation}\cite{soosairajEngagement}\cite{hermansFramework}
    
  \end{block}
  \vspace{2mm}

  \begin{alertblock}{Further Research Questions}
    \vspace{4mm}
    \begin{itemize}
      \item \textbf{Is CS student retention affected by the human language of the code?}
      \item \textbf{What code documentation is most effective for non-English speakers?}
      \item \textbf{How can we increase support for non-English languages in current IDEs?} % felienne framework
    \end{itemize}
  \end{alertblock}
